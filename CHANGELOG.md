# Changelog

All notable changes to PHOENIX will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [0.1.0] - 2026-09-13

### Added

- Initial release of PHOENIX platform
- Multi-provider AI support (Gemini, OpenAI, Anthropic, OpenRouter, Ollama)
- 76+ tools (terminal, filesystem, git, ADB, web, Python)
- MCP connector system with credential vault
- Layered memory system (session, project, preferences, decisions, errors, long-term)
- Web workspace with Phoenix Spatial Engine design system
- CLI with local and remote modes
- Telegram bot integration
- Voice input/output support
- Automation workflow engine with Zapier MCP integration
- Extension system
- Termux .deb packaging
- APT repository
- GitHub Pages deployment
- Direct ADB device control (no Shizuku/Rish)
- Subagent orchestration
- Agent modes (planner, builder, reviewer, tester, debugger)
